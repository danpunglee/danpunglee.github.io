# 기술 노트

작업하면서 배운 것과 문제를 해결한 과정을 짧게 기록합니다.

:::note 작성 예정
첫 노트를 준비하고 있습니다. 아래 주제부터 차례로 채워 갈 예정입니다.
:::

## 정리할 주제 {#topics}

- GitHub Organization과 GitHub Pages로 개인 허브 만들기
- 문서형(Docs) 레이아웃 설계 메모
- 작업 자동화와 도구 정리

## 노트 형식 {#format}

각 노트는 다음 순서로 씁니다.

1. **문제** — 무엇을 하려 했고 무엇이 막혔는지
2. **시도** — 확인한 것과 결과
3. **해결** — 최종 방법과 다음에 참고할 점
